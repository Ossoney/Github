# Finanzas Visuales (Expenless Style)

Aplicación de contabilidad personal "Local-First", rápida y visual.

## Características

- **Privacidad Total**: Datos guardados en tu dispositivo (IndexedDB).
- **Velocidad**: Carga instantánea y formulario rápido.
- **Visual**: Gráficos claros y alertas de presupuesto.

## Requisitos

Tienes que tener instalado [Node.js](https://nodejs.org/) (v18 o superior) en tu ordenador para ejecutar esta aplicación.

## Instalación

1. Abre una terminal en la carpeta raíz del proyecto:
   `cd C:\Users\OscarSson\Videos\GitHub\visualis`
2. Ejecuta `npm install` para descargar las librerías necesarias.
3. Ejecuta `npm run dev` para iniciar la aplicación.
4. Abre tu navegador en `http://localhost:3000` (o `http://<RED_LOCAL>:3000` desde el móvil).
