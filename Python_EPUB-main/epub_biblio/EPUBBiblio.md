# EPUB Biblio

**EPUB Biblio** es un programa freeware enfocado en la gestión visual y ligera de tu colección de archivos EPUB. 

Desarrollado con una arquitectura moderna (Python + React + SQLite), proporciona una experiencia fluida sin consumir grandes recursos de tu sistema.

## Características

- **Visualización Elegante**: Diseño modo oscuro, limpio y con animaciones fluidas.
- **Sin Alteraciones**: Al añadir tu biblioteca, los archivos originales se mantienen intactos. Solo extraemos la portada y los metadatos para visualizarlos de forma cómoda en la aplicación.
- **Rendimiento Ultrarrápido**: Búsqueda instantánea gracias al uso de SQLite y el frontend super rápido en React (Vite).
- **Procesamiento en Segundo Plano**: Añade miles de libros a la biblioteca visual mientras sigues usando la interfaz, gracias al backend manejador de tareas.
- **Auditoría (Logs)**: Todo lo que ocurre queda registrado en un archivo `epub_biblio.log` para tu paz mental.

# EPUB Biblio

**EPUB Biblio** is a freeware program focused on the visual and lightweight management of your EPUB file collection.

Developed with a modern architecture (Python + React + SQLite), it provides a fluid experience without consuming heavy system resources.

## Features

- **Elegant Visualization**: Dark mode design, clean interface, and fluid animations.
- **No Alterations**: When adding your library, the original files are kept intact. We only extract the cover and metadata to display them comfortably in the application.
- **Ultrafast Performance**: Instant search thanks to SQLite and a super fast React frontend (Vite).
- **Background Processing**: Add thousands of books to the visual library while you continue using the interface, thanks to the backend task manager.
- **Audit (Logs)**: Everything that happens is recorded in an `epub_biblio.log` file for your peace of mind.
