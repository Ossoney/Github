# Índice del Guiaburros Total de Seguridad Informática v2 (Debian 13 Trixie)

## Nivel 0: Plan de Seguridad Global
1.1. Introducción y objetivos del manual
1.2. Alcance (PCs, routers, switches, VMs nginx, cableado)
1.3. Política de seguridad general
1.4. Roles y responsabilidades (RACI matrix)
1.5. Clasificación de activos e información
1.6. Gestión de riesgos y presupuesto
1.7. Procedimiento básico de respuesta a incidentes
**Checklist Nivel 0**

## Nivel 1: Tipos y Clasificación de Seguridad
2.1. Tipos de seguridad: física, lógica, organizativa, personal
2.2. Modelos multinivel (TCSEC, capas OSI)
2.3. Clasificación de información: Público/Interno/Confidencial/Restringido
2.4. Controles preventivos, detectivos, correctivos
2.5. Marco normativo (ISO 27001, CIS Debian 12/13)
**Checklist Nivel 1**

## Nivel 2: Seguridad Física y Arranque Confiable
3.1. Protección de instalaciones (CCTV, cerraduras, alarmas)
3.2. Control físico de acceso (tarjetas RFID, biometría)
3.3. Seguridad del hardware y Firmware
   - 3.3.1. BIOS/UEFI: Password, Secure Boot y TPM 2.0 [1, 2]
   - 3.3.2. Control de puertos USB (USBGuard) y BadUSB
   - 3.3.3. Protección contra manipulación de arranque (Evil Maid)
3.4. Cableado estructurado seguro
3.5. Routers/Switches: Tamper-evident y etiquetado
**Checklist Nivel 2** (comandos: systemd-analyze pcrs, sbctl)

## Nivel 3: Seguridad Lógica - Sistema Base (Debian 13)
4.1. Hardware de red seguro
   - 4.1.1. Configuración switches (VLANs, port security)
   - 4.1.2. Router hardening (OpenWRT/Debian)
   - 4.1.3. Control MAC spoofing
4.2. Instalación segura Debian 13 "Trixie"
   - 4.2.1. Particionado moderno: LUKS2 con systemd-cryptenroll [3, 4]
   - 4.2.2. Sistema de archivos: /tmp en tmpfs (RAM) [5]
   - 4.2.3. Selección mínima de paquetes (netinst)
4.3. Hardening del Bootloader
   - 4.3.1. Transición a systemd-boot o GRUB firmado [6]
   - 4.3.2. Imágenes de Kernel Unificadas (UKI) [7]
4.4. Hardening básico del sistema
   - 4.4.1. Usuarios y PAM: Desactivar root, 2FA (libpam-google-authenticator)
   - 4.4.2. Permisos críticos y limpieza de setuid
   - 4.4.3. AppArmor: Auditoría y perfiles en modo 'enforce' [8]
4.5. Firewall base (nftables/UFW)
**Checklist Nivel 3**

## Nivel 4: Red, Servicios y Mantenimiento Avanzado
5.1. Arquitectura de red y DNS
   - 5.1.1. Segmentación y DMZ
   - 5.1.2. DNS seguro: DNSSEC y DoT con systemd-resolved [9, 10]
   - 5.1.3. VPN (WireGuard)
5.2. SSH hardening moderno (OpenSSH 10+)
   - 5.2.1. Eliminación de claves DSA, uso de Ed25519 [11]
   - 5.2.2. Configuración FIDO2/U2F para acceso SSH
5.3. Servicios web seguros (nginx)
   - 5.3.1. Cabeceras seguridad (CSP, HSTS)
   - 5.3.2. TLS 1.3 y ocultación de versión
5.4. Gestión de paquetes y vulnerabilidades
   - 5.4.1. Formato deb822 (/etc/apt/sources.list.d/debian.sources) [12, 13]
   - 5.4.2. unattended-upgrades y apt-listbugs
5.5. Monitorización y logs
   - 5.5.1. journald (logs firmados) y auditd
   - 5.5.2. Alertas básicas
5.6. Copias de seguridad 3-2-1 cifradas
**Checklist Nivel 4**

## Nivel 5: Auditoría, Cumplimiento y Respuesta
6.1. Auditorías automatizadas (Lynis, OpenSCAP) [14, 15]
6.2. Simulacros de incidentes (Ransomware, fallo TPM)
6.3. Forense digital básico
6.4. IDS/IPS (Suricata/Fail2ban) [16, 17]
6.5. Métricas de madurez
**Checklist Nivel 5**
