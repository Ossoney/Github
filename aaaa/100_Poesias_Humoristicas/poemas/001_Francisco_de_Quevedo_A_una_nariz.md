# Francisco de Quevedo: A una nariz

![Retrato de Francisco de Quevedo](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Quevedo_%28Copia_de_Vel%C3%A1zquez_y_Vel%C3%A1zquez%29.jpg/600px-Quevedo_%28Copia_de_Vel%C3%A1zquez_y_Vel%C3%A1zquez%29.jpg)

## El Autor (Biografía Entretenida)
El genio indiscutible del humor corrosivo, la sátira y el Barroco español. Francisco de Quevedo (1580-1645) era cojo, corto de vista y tenía un talento desproporcionado para insultar con extrema elegancia. Su pasatiempo favorito (además de escribir obras profundas y asombrosas sobre la muerte o el amor) era molestar a su archienemigo literario, Luis de Góngora. Llegó a comprar la casa donde Góngora vivía de alquiler... ¡solo para desahuciarlo! Su lengua afilada le costó el destierro y la cárcel varias veces, pero nos legó los versos más divertidos del Siglo de Oro.

## El Poema
Este es uno de los sonetos satíricos más célebres del idioma español (presuntamente dedicado, de nuevo, a la gran nariz de Luis de Góngora). Es un inventario exagerado, ridículo e hiperbólico de todas las cosas a las que puede compararse una nariz desproporcionadamente larga, desde un reloj de sol mal puesto hasta la "nariz de un sayón y escriba".

| Original (Español) | Traducción (Inglés/Referencial) |
|:---|:---|
| Érase un hombre a una nariz pegado, | There once was a man stuck to a nose, |
| érase una nariz superlativa, | there once was a superlative nose, |
| érase una nariz sayón y escriba, | there once was an executioner and scribe nose, |
| érase un peje espada muy barbado. | there once was a very bearded swordfish. |
|  |  |
| Era un reloj de sol mal encarado, | It was a poorly faced sundial, |
| érase una alquitara pensativa, | there once was a pensive alembic, |
| érase un elefante boca arriba, | there once was an elephant lying on its back, |
| era Ovidio Nasón más narizado. | it was Ovid Naso, but nosier. |
|  |  |
| Érase un espolón de una galera, | There once was the ram of a galley, |
| érase una pirámide de Egipto, | there once was an Egyptian pyramid, |
| las doce Tribus de narices era. | it was the Twelve Tribes of noses. |
|  |  |
| Érase un naricísimo infinito, | There once was an infinite nose-ness, |
| muchisimo nariz, nariz tan fiera | very much a nose, a nose so fierce |
| que en la cara de Anás fuera delito. | that on the face of Annas it would be a crime. |
