# Baltasar del Alcázar: Tres cosas me tienen preso

![Retrato representativo/Época](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Baltazar.jpg/600px-Baltazar.jpg)

## El Autor (Biografía Entretenida)
Un "bon vivant" (o un glotón brillante) del Siglo de Oro español. Baltasar del Alcázar (1530-1606), nacido en Sevilla, fue militar, prisionero de galeras brevemente, alcaide y administrador... pero sobre todo, fue un poeta excepcionalmente festivo e irónico. Mientras otros de su época (Garcilaso, Fray Luis) se dedicaban intensamente a escribir pastorales tristes, lloros al amado ausente o elevaciones místicas a Dios, a Baltasar lo que le inspiraba hacer versos majestuosos eran... las berenjenas con queso y el jamón. 

## El Poema
Un clásico humorístico absoluto. Empieza como un poema de amor cortés típico en el que el poeta parece confesar un desgarbado sufrimiento por amor hacia Inés... para acto seguido destrozar las expectativas confesando que su afecto por ella compite seriamente con un plato de comida deliciosa.

| Tres cosas me tienen preso | Three things have me imprisoned |
| de amores el corazón, | the heart with love, |
| la bella Inés, el jamón, | the beautiful Inés, the ham, |
| y berenjenas con queso. | and eggplants with cheese. |
|  |  |
| Esta Inés, amantes, es | This Inés, lovers, is |
| quien tuvo en mí tal poder, | who held such power in me, |
| que me hizo aborrecer | that she made me abhor |
| todo lo que no era Inés. | everything that was not Inés. |
|  |  |
| Trájome un año sin seso, | She drove me crazy for a year, |
| hasta que en una ocasión | until on one occasion |
| me dio a merendar jamón | she gave me ham for a snack |
| y berenjenas con queso. | and eggplants with cheese. |
|  |  |
| Fue de Inés la primer palma; | The first palm was for Inés; |
| pero ya juzgarse ha visto | but it has already been judged |
| entre todos ellos pleito, | among them a lawsuit, |
| a quién le dará mi alma. | as to whom my soul will be given. |
