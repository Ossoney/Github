# Mary Shelley: A Dirge

![Mary Shelley](https://upload.wikimedia.org/wikipedia/commons/thumb/1/18/Mary_Wollstonecraft_Shelley_Rothwell.jpg/600px-Mary_Wollstonecraft_Shelley_Rothwell.jpg)

## La Autora (Biografía Entretenida)
Impetuosa fabulosa fúnebre fúnebre asombrosamente fúnebre. Mary Shelley a a inmenso a a famosa.

## El Poema
Una a inmensa amarga.

| Original (Inglés) | Traducción (Español) |
|:---|:---|
| Weep for the dead! | ¡Llorad por los muertos! |
| For they are gone | Porque se han ido |
| To sleep in peace | A dormir en paz |
| And wake no more | Y no despertar más. |
|  |  |
| *(A Dirge)* | *(Elegía)* |
