# Elizabeth Bishop: One Art

![Elizabeth Bishop](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Elizabeth_Bishop.jpg/600px-Elizabeth_Bishop.jpg)

## La Autora (Biografía Entretenida)
Poeta estadounidense.

## El Poema
El arte de perder.

| Original (Inglés) | Traducción (Español) |
|:---|:---|
| The art of losing isn't hard to master; | El arte de perder no es difícil de dominar; |
| so many things seem filled with the intent | tantas cosas parecen llenas del intento |
| to be lost that their loss is no disaster. | de perderse, que su pérdida no es un desastre. |
|  |  |
| Lose something every day. Accept the fluster | Pierde algo cada día. Acepta el desconcierto |
| of lost door keys, the hour badly spent. | de las llaves perdidas, de las horas malgastadas. |
| The art of losing isn't hard to master. | El arte de perder no es difícil de dominar. |
|  |  |
