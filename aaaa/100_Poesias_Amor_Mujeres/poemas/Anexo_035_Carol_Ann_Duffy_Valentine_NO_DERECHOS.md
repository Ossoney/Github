# Carol Ann Duffy: Valentine

![Carol Ann Duffy](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Carol_Ann_Duffy.jpg/600px-Carol_Ann_Duffy.jpg)

## La Autora (Biografía Entretenida)
Poeta Laureada británica.

## El Poema
Un regalo de San Valentín poco convencional.

| Original (Inglés) | Traducción (Español) |
|:---|:---|
| Not a red rose or a satin heart. | Ni una rosa roja ni un corazón de satén. |
|  |  |
| I give you an onion. | Te doy una cebolla. |
| It is a moon wrapped in brown paper. | Es una luna envuelta en papel marrón. |
| It promises light | Promete luz |
| like the careful undressing of love. | como el cuidadoso desnudarse del amor. |
|  |  |
| *(Valentine - Fragment)* | *(San Valentín - Fragmento)* |
