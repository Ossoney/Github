# Wislawa Szymborska: Nada dos veces (Nic dwa razy)

![Wislawa Szymborska](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Wyslawa_Szymborska.jpg/600px-Wyslawa_Szymborska.jpg)

## La Autora (Biografía Entretenida)
Brillante fúnebre asombrosa.

## El Poema
El momento único.

| Original (Polaco - Tr) | Traducción (Español) |
|:---|:---|
| Nic dwa razy się nie zdarza | Nada sucede dos veces |
| i nie zdarzy. Z tej przyczyny | ni sucederá. Por esta razón |
| zrodziliśmy się bez wprawy | nacimos sin práctica |
| i pomrzemy bez rutyny. | y moriremos sin rutina. |
|  |  |
| *(Nic dwa razy - Fragment)* | *(Nada dos veces - Extracto)* |
