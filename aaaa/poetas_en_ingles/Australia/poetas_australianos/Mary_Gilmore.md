# Mary Gilmore (1865–1962)

## Biografía Sentimental

Dame Mary Gilmore es una de las más grandes matriarcas de la literatura australiana, cuyo rostro ilustra actualmente el billete de diez dólares australiano. Fue una activista incansable, educadora, periodista y utopista (participó en la famosa "Nueva Australia" en Paraguay en 1893). En Paraguay se casó con un esquilador victoriano, William Gilmore, al que amó profundamente a pesar de las inmensas dificultades de su vida agraria inicial. Gran parte de su poesía gira en torno al matrimonio, la maternidad, el sacrificio femenino y la lealtad rural. Su visión del amor no es etérea; es un amor de sangre, trabajo, hijos, dolor compartido y la resiliencia feroz de la mujer ante las adversidades del campo australiano y sudamericano. Sus poemas son célebres por su franqueza emocional: el amor de Gilmore es apasionado pero maduro, profundamente humano y apegado a la tierra.

## 10 Poemas de Amor (Bilingüe)

### 1. Eve-Song
| Original (English) | Traducción (Español) |
|:---|:---|
| I span and Eve span | Yo hilaba y Eva hilaba |
| A thread to bind the heart of man; | un hilo para atar el corazón del hombre; |
| But the heart of man was a wandering thing | pero el corazón del hombre era algo errante |
| That came and went with little to bring: | que iba y venía con poco que aportar: |
| Nothing he minded what we made, | nada le importaba lo que hacíamos, |
| As here he loitered, and there he stayed. | mientras holgazaneaba aquí y se quedaba allá. |
|  |  |
| I span and Eve span | Yo hilaba y Eva hilaba |
| A thread to bind the heart of man; | un hilo para atar el corazón del hombre; |
| But the more we span the more we found | pero cuanto más hilábamos más descubríamos |
| It wasn't his heart but ours we bound. | que no atábamos el suyo sino el nuestro. |
| For children gathered about our knees: | Porque los niños se reunieron alrededor de nuestras rodillas: |
| The thread was a chain that stole our ease. | el hilo era una cadena que nos robó la comodidad. |
|  |  |
| And one of us learned in our children's eyes | Y una de nosotras aprendió en los ojos de nuestros niños |
| That more than man was love and prize. | que más que el hombre era el amor y el premio. |
| But deep in the heart of one of us lay | Pero muy en el corazón de una de nosotras yacía |
| A root of loss and hidden dismay. | una raíz de pérdida y consternación oculta. |
|  |  |
| He said he was strong. He had no strength | Él dijo que era fuerte. No tenía otra fuerza |
| But that which comes of breadth and length. | que la que viene de la anchura y la longitud. |
| He said he was fond. But his fondness proved | Él dijo que era cariñoso. Pero su cariño demostró ser |
| The mask of self when he said he loved. | la máscara del propio yo cuando decía amar. |
|  |  |
| I span and Eve span | ¡Yo hilaba y Eva hilaba |
| A thread to bind the heart of man! | un hilo para atar el corazón del hombre! |

### 2. Marri'd
| Original (English) | Traducción (Español) |
|:---|:---|
| It's singin' in an' out, | Es cantar por dentro y por fuera, |
| An' feelin' full of grace; | y sentirse llena de gracia; |
| Here 'n' there, up an' down, | aquí y allá, arriba y abajo, |
| An' round about th' place. | y por todo el lugar. |
|  |  |
| It's rollin' up your sleeves, | Es arremangarse las mangas, |
| An' whitenin' up the hearth, | y blanquear la chimenea, |
| An' sweepin' out th' floors, | y barrer los suelos, |
| An' sweepin' out th' path; | y barrer el sendero; |
|  |  |
| It's clatterin' t' th' well, | Es ir repiqueteando hacia el pozo, |
| An' clatterin' back again; | y volver repiqueteando de nuevo; |
| It's makin' bread an' scones, | es hacer pan y bollos, |
| An' singin' in the rain; | y cantar bajo la lluvia; |
|  |  |
| It's bakin' on th' coals, | Es hornear en las brasas, |
| An' cookin' by th' fire, | y cocinar junto al fuego, |
| An' watchin' for th' man | y vigilar en espera del hombre |
| Who brings your heart's desire. | que trae el deseo de tu corazón. |

### 3. Never Admit the Pain
| Original (English) | Traducción (Español) |
|:---|:---|
| Never admit the pain, | Nunca admitas el dolor, |
| Bury it deep; | entiérralo profundo; |
| Only the weak complain, | solo los débiles se quejan, |
| Complaint is cheap. | la queja es barata. |
|  |  |
| Cover thy wound, fold down | Cubre tu herida, dobla hacia abajo |
| Its curtained place; | su espacio encortinado; |
| Silence is still a crown, | el silencio sigue siendo una corona, |
| Courage a grace. | el valor una gracia. |
|  |  |
| For love will turn to thee | Porque el amor se volverá hacia ti |
| If thou art strong, | si eres fuerte, |
| But love will flee from thee | pero el amor huirá de ti |
| At the first song | a la primera canción |
| Of weeping and of tears. | de sollozos y de lágrimas. |

### 4. The Passionate Heart
| Original (English) | Traducción (Español) |
|:---|:---|
| O Life, I called to thee, | Oh, Vida, a ti clamé: |
| "What wilt thou give?" | "¿Qué es lo que darás?" |
| Life said, "A passionate heart | La vida dijo: "Un corazón apasionado |
| That thou mayst live. | para que puedas vivir. |
|  |  |
| "It shall be bound with pain, | Estará atado con dolor, |
| And torn with ruth; | y desgarrado por la lástima; |
| But it shall sing for love, | pero cantará por el amor, |
| And fight for truth." | y luchará por la verdad." |

### 5. Nurse No Longing
| Original (English) | Traducción (Español) |
|:---|:---|
| Nurse no longing; let it go: | No alimentes ningún anhelo; déjalo ir: |
| Winter cannot stop the snow. | el invierno no puede detener la nieve. |
| Nurse no longing; turn thy head: | No alimentes ningún anhelo; vuelve la cabeza: |
| Thou canst not wake the happy dead. | no puedes despertar a los felices muertos. |
|  |  |
| Love will pass, and pain will pass, | El amor pasará, y el dolor pasará, |
| As the shadows on the grass. | como las sombras en la hierba. |
| What is given, let it be; | Lo que es dado, déjalo ser; |
| Set the captive sorrow free! | ¡libera a la pena cautiva! |

| Much must be lost, | mucho debe ser perdido, |
| Before the heart | antes de que el corazón |

### 7. The Woman of My Story
| Original (English) | Traducción (Español) |
|:---|:---|
| The woman of my story gave | La mujer de mi historia dio |
| Her all for one, a selfish knave. | su todo por uno, un bribón egoísta. |
| She gave her youth, she gave her peace, | Dio su juventud, dio su paz, |
| She only asked that love not cease. | solo pidió que el amor no cesara. |
|  |  |
| Men pitied her, because she stood | Los hombres se compadecieron de ella, porque quedó |
| Denied the crown of womanhood. | privada de la corona de la feminidad. |
| But she had found a deeper spring: | Pero ella había encontrado un manantial más profundo: |
| To love is better than the King. | amar es mejor que el Rey. |

### 8. Autumn Leaves
| Original (English) | Traducción (Español) |
|:---|:---|
| The autumn leaves are falling down, | Las hojas de otoño están cayendo, |
| The golden, and the red, and brown. | las doradas, y las rojas, y las marrones. |
| And as they fall, my heart can see | Y mientras caen, mi corazón puede ver |
| The love that used to comfort me. | el amor que solía consolarme. |
|  |  |
| The summer time is gone and past, | El tiempo del verano se ha ido y ha pasado, |
| The winter chill is coming fast; | el frío del invierno se acerca rápido; |
| Yet in my mind the sun is warm, | sin embargo en mi mente el sol es cálido, |
| Above the memory of the storm. | por encima del recuerdo de la tormenta. |

### 9. Sweetheart
| Original (English) | Traducción (Español) |
|:---|:---|
| O sweetheart, early sweetheart, | ¡Oh cariño, temprano cariño, |
| The grass is green on the hill! | la hierba está verde en la colina! |
| And if my tears are failing, | Y si mis lágrimas están fallando, |
| I hold your image still. | aún sostengo tu imagen. |
|  |  |
| The years have been a burden, | Los años han sido una carga, |
| The road was rough and long; | el camino fue áspero y largo; |
| But I have kept your whisper, | pero he guardado tu susurro, |
| And turned it to a song. | y lo he convertido a una canción. |

### 10. The Final Grace
| Original (English) | Traducción (Español) |
|:---|:---|
| We ask for love, we ask for truth, | Pedimos amor, pedimos verdad, |
| In the hot, impulsive days of youth. | en los calurosos e impulsivos días de juventud. |
| But when the evening shadows spread, | Pero cuando las sombras del anochecer se extienden, |
| We only ask a quiet bed, | solo pedimos una cama tranquila, |
|  |  |
| And one who sits beside the fire, | y a alguien que se siente junto al fuego, |
| When all the flames of earth expire, | cuando todas las llamas de la tierra expiran, |
| To hold a hand and share the peace, | para sostener una mano y compartir la paz, |
| When all the worldly clamours cease. | cuando todos los clamores mundanos cesan. |
