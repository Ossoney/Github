# Li Qingzhao (李清照)
*(1084 – c. 1151) · Jinan, China*

## Biografía sentimental y erótica

Li Qingzhao es considerada la mayor poetisa de la historia china. Nacida en una familia intelectual de la provincia de Shandong, se casó enamorada con Zhao Mingcheng, un erudito coleccionista de antigüedades con quien vivió dos décadas de idilio literario y amoroso. Escribían poemas el uno para el otro, competían con juegos de citas, se enviaban *ci* (poemas en forma musical) desde la distancia cuando viajaban por separado.

La invasión de los Jin del Norte destruyó ese mundo. Zhao Mingcheng murió en 1129 y Li Qingzhao huyó hacia el sur, refugiada, perdiendo en la huida la mayor parte de su colección de libros y antiqüedades. En el exilio se volvió a casar —brevemente, por necesidad económica— con un hombre brutal al que pronto denunció ante los tribunales y divorció. Sus últimos poemas son de una melancolía sin fondo.

Pero sus poemas más célebres son los de la pasión: describen el deseo físico de la joven que espera al marido en viaje, el cuerpo empapado de vino y perfume, el columpio en el jardín donde su cabeza golpeó al amado accidentalmente.

## Sus 10 mejores poemas eróticos y apasionados

### Poema 1: Aire de Como Sueño (如梦令)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 常记溪亭日暮，沉醉不知归路 | Recuerdo aquel atardecer en el pabellón del arroyo, |
| 兴尽晚回舟，误入藕花深处 | ebria, sin saber el camino de regreso. |
| 争渡，争渡，惊起一滩鸥鹭 | Saciado el placer, tardé en volver a remar, |
| 常记溪亭日暮 | me adentré por error en lo más hondo de los lotos. |
|  | Remar, remar: espanté una playa de gaviotas y garzas. |

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|

| 露浓花瘦，薄汗轻衣透 | El rocío espeso, la flor escuálida, el sudor suave tras la ropa ligera. |
| 见客入来，袜刬金钗溜 | Viendo entrar al visitante, con sólo mis medias, se me cae el pasador de oro. |
| 和羞走，�倚门回首，却把青梅嗅 | Me escapo avergonzada; apoyada en la puerta me vuelvo a mirar atrás, |
|  | y finjo oler una ciruela verde. |

### Poema 3: La añoranza del amado (一剪梅)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 红藕香残玉簟秋，轻解罗裳，独上兰舟 | Los lotos rojos marchitan, otoño en la estera de jade; suelto mi vestido suave |
| 云中谁寄锦书来？雁字回时，月满西楼 | y subo sola a la barca de orquídeas. |
| 花自飘零水自流，一种相思，两处闲愁 | ¿Quién me envía una carta bordada desde las nubes? |
| 此情无计可消除，才下眉头，却上心头 | Cuando las aves regresan, la luna llena ilumina la torre del oeste. |
|  | Las flores caen solas, el agua fluye sola: |
|  | un solo amor, tristeza en dos lugares. |
|  | Este sentimiento no puede eliminarse: |
|  | apenas baja del ceño, ya sube al corazón. |

### Poema 4: Melancolía lenta (声声慢)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 寻寻觅觅，冷冷清清，凄凄惨惨戚戚 | Busco, busco; frío, vacío; triste, desolada, miserable. |
| 乍暖还寒时候，最难将息 | En este tiempo que pasa del calor al frío, |
| 三杯两盏淡酒，怎敌他，晚来风急 | lo más difícil es descansar el cuerpo. |
| 雁过也，正伤心，却是旧时相识 | Tres tazas, dos copas de vino suave: ¿cómo vencer |
| 满地黄花堪摘，憔悴损，如今有谁堪摘 | el viento violento que llega al atardecer? |
|  | Pasan los gansos: justo cuando me duele el corazón, |
|  | son viejos conocidos de otros tiempos. |

### Poema 5: Añoranza de Zhao Mingcheng (醉花阴)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 薄雾浓云愁永昼，瑞脑消金兽 | Neblina tenue, nubes densas, triste el día eterno; |
| 佳节又重阳，玉枕纱厨，半夜凉初透 | el incienso se consume en el quemador de oro. |
| 东篱把酒黄昏后，有暗香盈袖 | Otro Festival de Doble Nueve; en la almohada de jade, |
| 莫道不消魂，帘卷西风，人比黄花瘦 | en el dosel de seda, el frío de media noche empieza a penetrar. |
|  | Al este, junto a la valla, bebo vino en el crepúsculo; |
|  | una fragancia suave llena mis mangas. |
|  | No digas que no me consume el alma: |
|  | el viento del oeste levanta las cortinas, y yo |
|  | estoy más delgada que las flores amarillas. |

### Poema 6: Primavera solitaria (浣溪沙)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 淡荡春光寒食天，玉炉沉水袅残烟 | Plena y suave, la luz de primavera en el día festivo; |
| 梦回山枕隐花钿 | el quemador de jade humea con áloe apagado, humo residual. |
| 海燕未来人斗草，江梅已过柳生绵 | Soñando, vuelvo en mí; en la almohada de montaña, escondidas mis joyas de flor. |
| 黄昏疏雨湿秋千 | Las golondrinas del mar aún no llegan; las mujeres juegan al concurso de hierbas. |
|  | El ciruelo del río ya ha pasado; el sauce esparce su pelusa. |
|  | Al atardecer, lluvia ligera moja el columpio. |

### Poema 7: La última flor de primavera (怨王孙)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 湖上风来波浩渺，秋已暮，红稀香少 | El viento llega sobre el lago, las olas vastas; |
| 水光山色与人亲，说不尽，无穷好 | el otoño ya declina, escasas las flores rojas, poca la fragancia. |
| 莲子已成荷叶老，清露洗，苹花汀草 | La luz del agua y el color de la montaña son íntimos con las personas; |
| 眠沙鸥鹭不回头，似也恨，人归早 | no se puede decir, bondad sin fin. |

### Poema 8: Noche de primavera — insomnio

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 春到长门春草青，红梅些子破，未开匀 | La primavera llega al palacio abandonado: hierba verde; |
| 碧云笼碾玉成尘，留晓梦，惊破一瓯春 | una pequeña ruptura en los ciruelos rojos, aún no uniformemente abiertos. |
| 昨夜雨疏风骤 | Nubes azules moldean el jade hasta hacerlo polvo; |
| 浓睡不消残酒 | guardando el sueño del alba, se rompe de golpe una taza de primavera. |

### Poema 9: Ansia de amor (多丽·咏白菊)

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 小楼寒，夜长帘幕低垂 | La pequeña torre se enfría; la noche es larga, las cortinas cuelgan bajas. |
| 恨萧萧无情风雨，夜来揉损琼肌 | Odio el viento y la lluvia despiadados que de noche masajean |
| 也不似贵妃醉脸，也不似孙寿愁眉 | y dañan la piel de jade. |
| 韩令偷香，徐娘傅粉，莫将比拟未新奇 | Tampoco se parece al rostro ebrio de Guifei, |
| 细看取，屈平陶令，风韵正相宜 | ni a las cejas tristes de Sun Shou. |

### Poema 10: El retorno — poema de despedida

| CHINO (original) | ESPAÑOL (traducción) |
|:---|:---|
| 生当作人杰，死亦为鬼雄 | Viva, debería ser héroe entre los vivos; |
| 至今思项羽，不肯过江东 | muerta, sería heroína entre los espíritus. |
| 物是人非事事休，欲语泪先流 | Hasta hoy pienso en Xiang Yu, |
| 闻说双溪春尚好，也拟泛轻舟 | que no quiso cruzar el río hacia el este. |
| 只恐双溪舴艋舟，载不动许多愁 | Las cosas permanecen, las personas cambian: todo se detiene. |
|  | Cuando quiero hablar, las lágrimas fluyen primero. |
|  | Dicen que los arroyos gemelos en primavera son aún hermosos; |
|  | también pienso en navegar en una barca ligera. |
|  | Sólo temo que la pequeña barca de los arroyos gemelos |
|  | no pueda cargar tanta tristeza. |
