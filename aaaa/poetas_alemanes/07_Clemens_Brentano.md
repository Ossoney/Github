# Clemens Brentano

**Fechas:** 1778 - 1842

## Biografía

Insigne representante de la escuela del Romanticismo de Heidelberg, Clemens Brentano destacó por haber revivido el folclore alemán a través de la publicación junto a Achim von Arnim (su cuñado) de la recopilación de cantos populares 'Des Knaben Wunderhorn'.

Su vida sentimental fue intensamente inestable y arrojada. Estuvo casado con la notable intelectual Sophie Mereau (con gran sufrimiento debido a la muerte de los hijos de ambos en la infancia y la posterior muerte de ella durante un parto), y más tarde un desastroso matrimonio con Auguste Bußmann. Su alma atormentada se debatía constantemente entre el deseo sensual erótico y el misticismo católico devoto.

En la poética de Brentano, el amor adquiere formas melódicas hechiceras y embriagadoras. A menudo, recurre a figuras como la sirena del Rin (Lore Lay) que él mismo popularizó en un balada, mostrando que el amor puede ser tanto una dulce melodía como un embrujo demoníaco letal que arrastra al hombre hacia su disolución.

## Poemas

### 1. Der Spinnerin Nachtlied / La Canción Nocturna de la Hilandera

| Alemán | Castellano |
|:---|:---|
| Es sang vor langen Jahren | Cantaba hace largos años |
| Wohl auch die Nachtigall, | Quizás también el ruiseñor, |
| Das war wohl süßer Schall, | Ese era quizás dulce sonido, |
| Da wir zusammen waren. | Cuando nosotros juntos estábamos. |
| &nbsp; | &nbsp; |
| Ich sing und kann nicht weinen, | Yo canto y no puedo llorar, |
| Und spinne so allein | Y hilo así sola |
| Den Faden klar und rein | Al hilo claro y puro |
| Solang der Mond wird scheinen. | Mientras la luna brillará. |

### 2. Sprich aus der Ferne / Habla desde la Lejanía

| Alemán | Castellano |
|:---|:---|
| Sprich aus der Ferne, | ¡Habla desde la lejanía, |
| Heimliche Welt, | Secreto mundo, |
| Die sich so gerne | Que tan gustosamente |
| Zu mir gesellt! | A mí se asocia! |
| &nbsp; | &nbsp; |
| Wenn das Abendrot niedergesunken, | Cuando el arrebol caído hacia abajo, |
| Wenn die müde Natur schon entschlafen; | Cuando la cansada naturaleza ya dormida; |
| Alles nur Liebe, die Herzen trunken, | Todo solo amor, los corazones ebrios, |
| Als wir zum ersten Mal flüsternd uns trafen. | Cuando nosotros por primera vez susurrando nos encontramos. |

### 3. O kühler Wald / Oh Genial Bosque

| Alemán | Castellano |
|:---|:---|
| O kühler Wald, | Oh fresco bosque, |
| Wo rauschest du, | ¿Dónde murmuras tú, |
| In dem mein Liebchen geht? | En el que mi amada va (camina)? |
| O Widerhall, | Oh Eco, |
| Wo lauschest du, | ¿Dónde escuchas tú, |
| Der gern mein Lied versteht? | El que gustoso mi canción entiende? |
| &nbsp; | &nbsp; |
| Im Herzen tief, | En el corazón profundo, |
| Da rauscht der Wald, | Allí murmura el bosque, |
| In dem mein Liebchen geht. | En el que mi amada va. |
| In Schmerzen schlief | En dolores durmió |
| Der Widerhall, | El Eco, |
| Der gern mein Lied versteht. | Que gustoso mi canción entiende. |

### 4. Abendständchen / Serenata Nocturna

| Alemán | Castellano |
|:---|:---|
| Hör, es klagt die Flöte wieder, | Oye, se queja la flauta de nuevo, |
| Und die kühlen Bronnen rauschen, | Y las frescas fuentes murmuran, |
| Golden wehn die Töne nieder, | Dorados ondean los tonos hacia abajo, |
| Stille, stille, laß uns lauschen! | ¡Calla, calla, déjanos escuchar! |
| &nbsp; | &nbsp; |
| Holdes Bitten, mild Verlangen, | Dulce ruego, apacible deseo, |
| Wie es süß zum Herzen spricht! | ¡Cómo de dulcemente al corazón habla! |
| Durch die Nacht, die mich umfangen, | A través de la noche, que a mí envolvió, |
| Blickt zu mir der Liebe Licht. | Mira hacia mí del amor la luz. |

### 5. Wiegenlied / Canción de Cuna

| Alemán | Castellano |
|:---|:---|
| Singet leise, leise, leise, | Cantad suave, suave, suave, |
| Singt ein flüsternd Wiegenlied, | Cantad una susurrante canción de cuna, |
| Von dem Monde lernt die Weise, | De la luna aprended la melodía, |
| Der so still am Himmel zieht. | La que tan silenciosa en el cielo tira (se mueve). |
| &nbsp; | &nbsp; |
| Singt ein Lied so süß gelinde, | Cantad una canción tan dulce (y) apacible, |
| Wie die Quellen auf den Kieseln, | Como las fuentes sobre los guijarros, |
| Wie die Bienen um die Linde | Como las abejas alrededor del tilo |
| Summen, murmeln, flüstern, rieseln. | Zumban, murmuran, susurran, gotean. |

### 6. Lore Lay (Loreley) / Lore Lay (Loreley)

| Alemán | Castellano |
|:---|:---|
| Zu Bacharach am Rheine | En Bacharach en el Rin |
| Wohnt eine Zauberin, | Habitaba una hechicera, |
| Die war so schön und feine | Ella era tan hermosa y fina |
| Und riß viel Herzen hin. | Y arrastraba a muchos corazones allí. |
| &nbsp; | &nbsp; |
| Und machte viel zuschanden | Y hacía muchos a (la) ruina |
| Der Männer rings umher, | De los hombres alrededor por doquier, |
| Aus ihren Liebesbanden | De sus ataduras de amor |
| War keine Rettung mehr. | No había ninguna salvación más. |

### 7. Wenn die Sonne weggegangen / Cuando el Sol se ha Ido

| Alemán | Castellano |
|:---|:---|
| Wenn die Sonne weggegangen, | Cuando el sol se ha ido, |
| Kommt der Sternlein goldne Pracht; | Viene de las estrellitas el dorado esplendor; |
| Wenn die Blümlein alle hangen, | Cuando las florecillas todas cuelgan, |
| Blicken sie so hell zur Nacht. | Miran ellas tan claras hacia la noche. |
| &nbsp; | &nbsp; |
| Wenn ich auch nicht bei dir bin, | Aunque yo no contigo esté, |
| Bleibt mein Herz doch stets dir nah; | Queda mi corazón sin embargo siempre de ti cerca; |
| Fliegt die Lieb auf Wolken hin, | Si vuela el amor sobre nubes allí, |
| Ist mein Geist dir unsichtbar da. | Está mi espíritu para ti invisible allí. |

### 8. Schwanenlied / El Canto del Cisne

| Alemán | Castellano |
|:---|:---|
| Ach, mein Lieb, nur kurze Zeit | ¡Ay, mi amor, solo corto tiempo |
| Währt das Glück der Erden! | Dura la dicha de las tierras! |
| Heute noch in inniger Freud', | Hoy aún en íntima alegría, |
| Morgen muß geweinet werden. | Mañana debe llorarse ser. |
| &nbsp; | &nbsp; |
| Bleibt uns nur die Melodie | Nos queda solo la melodía |
| Von dem ew'gen Lieben; | Del eterno amar; |

| Stets verjüngt, von Göttern betrieben. | Siempre rejuvenecida, por dioses impulsada. |

### 9. Sehnsucht / Añoranza

| Alemán | Castellano |
|:---|:---|
| Ich wollte, ich läg' bei meinem Lieb, | Yo quería, yo yaciese junto a mi amor, |
| Doch ach, er ist so weit von mir. | Pero ay, él está tan lejos de mí. |
| Der kalte Wind, der mich so trieb, | El frío viento, que a mí tan impulsó, |
| Er bläst so kalt von meiner Tür. | Él sopla tan frío desde mi puerta. |
| &nbsp; | &nbsp; |
| Das trübe Licht, die stille Nacht, | La turbia luz, la silenciosa noche, |
| Erinnern mich der treuen Schwur; | Me recuerdan del fiel juramento; |
| Oh Herzelei, in dunkler Pracht, | Oh tormento del corazón, en oscuro esplendor, |
| Wir folgten stets nur einer Spur. | Nosotros seguíamos siempre solo un rastro. |

### 10. Gute Nacht, mein Herz / Buenas Noches, mi Corazón

| Alemán | Castellano |
|:---|:---|
| Gute Nacht, mein liebes Herze, | Buenas noches, mi querido corazón, |
| Es ist nun die Zeit zur Ruh. | Es ahora el tiempo hacia el descanso. |
| Ohne Leiden, ohne Schmerze | Sin sufrimientos, sin dolores |
| Tu die müden Augen zu. | Cierra los cansados ojos. |
| &nbsp; | &nbsp; |
| Träum von süßen Himmelswellen, | Sueña de dulces olas celestiales, |
| Wo die Engel mit dir weilen; | Donde los ángeles contigo se demoran; |
| Lass die Tränen nicht mehr quellen, | No dejes a las lágrimas ya más brotar, |
| Morgen wird das Glück uns eilen. | Mañana la dicha nos apresurará. |
